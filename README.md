# DemonStats

A dark-themed Geometry Dash demon tracking website.

## Files

- index.html — website structure
- styles.css — website design
- app.js — leaderboards, demon lists and demo submission form

## GitHub Pages setup

1. Upload all three files to the root of the `demonstats` repository.
2. Open Settings.
3. Open Pages.
4. Select Deploy from a branch.
5. Select `main`.
6. Select `/(root)`.
7. Save and wait for deployment.

Your website should be available at:

https://YOUR-USERNAME.github.io/demonstats/

## Current features

- Home page
- Classic Demon list
- Platformer Demon list
- Demon Stars leaderboard
- Moon Points leaderboard
- List Points leaderboard
- Example MATIPAS profile
- Demo record submission form

## Important

The current submission form uses browser localStorage.

It does not yet provide:
- Real player accounts
- Geometry Dash account verification
- A shared online database
- Moderator approval
- Real global leaderboards

A backend and database are required for those features.

Never ask players for their Geometry Dash passwords.
